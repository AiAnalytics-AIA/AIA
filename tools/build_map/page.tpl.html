    The research flow

    The eleven stages a study goes through, in six phases. Pick a stage to see what it is for, what flows into it, what it hands on, what is built and what is missing. The Lead works across all of them.

    Build sequence

    Every open MVP chunk in the wave it may integrate in, from the execution contracts. A wave is done only when every chunk in it is ticked. Within a wave, groups are in dependency order: a group lists the groups it needs, and a chunk should not merge before them. The current wave is the earliest with open work.

    Configuration

    A feature that is built but not switched on does not exist for a user. Each row is a switch or resource the MVP needs (master plan §4), who sets it, how to see it is on, and what develop has now. Done means merged, switched on and seen working on develop.
