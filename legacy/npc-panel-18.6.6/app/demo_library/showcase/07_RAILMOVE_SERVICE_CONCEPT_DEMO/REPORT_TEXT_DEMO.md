# RailMove Service Concept DEMO

## Executive answer
Nejlépe funguje FlexPass: měsíční balíček s kredity, automatickou nejlepší cenou a jednoduchou změnou rezervace. Čisté předplatné je srozumitelné pro dojíždějící, ale příliš úzké pro širší trh.

## Doporučení
GO — FlexPass jako hlavní koncept; komunikovat „nejlepší cena bez počítání“ a flexibilitu změn.

## Hlavní zjištění
- Flexibilita změny je téměř stejně důležitá jako cena.
- Commuter Pass je silný jen u každodenních dojíždějících.
- Membership Plus potřebuje konkrétnější benefity, jinak působí jako příplatek.
- Best-price mechanism zvyšuje vnímanou férovost, pokud je vysvětlen jednoduše.

## Limity
- Preference konceptu není skutečná usage behavior.
- Tarif vyžaduje ekonomický model výnosnosti.
- Při výpadcích služby se value perception rychle zhoršuje.
