# Interaction inventory

Generated by `npm run docs` from `src/model/inventory.ts`. Inspected: AiAnalytics-AIA/AIA `develop` @ `50547cdc8d90a282af1d2e94bcd8e835df7178f9`; open-webui/open-webui `dev` @ `aa8ce52c7a3afbb164bc16a3b7c20e40ba6390ed`.

Every action, and the path it takes: GUI (visual only), typed command (an AIA application command), lookup (read-only), worker (bounded specialist AI), deterministic engine, Deep Research, human decision. UI controls and the Lead call the same commands (`src/app/commands.ts`).

| Action | Path | Detail |
|---|---|---|
| Open a stage, focus an element, select a map object, open the inspector | GUI | visual.open / select / inspect: never changes research content |
| Apply a display filter on the Sociomap | GUI | visual.filter, logged; artifact unchanged |
| Edit an element by hand | Typed command | working.edit → autosaved working copy; Lead notices |
| Accept a working copy as a revision | Human decision | working.accept (UI only); downstream reopens after a run |
| Lead reads the questionnaire / pair / state | Lookup | read-only card; no cost |
| Optimise the questionnaire; rebuild a stale proposal | Worker | bounded agent job → proposal with baseRev |
| Accept / reject a proposal | Human decision | proposal.accept refuses non-human callers and stale bases |
| Check readiness / coverage | Deterministic engine | readiness, research_trace, outlook |
| Start a run | Human decision | decision card → run.start; spend confirmation only at the limit |
| Aggregate, Sociomap | Deterministic engine | no model; frozen artifacts |
| Analysis modules, report composition | Worker | aia.analysis.module, report per section; evidence gate decides |
| Verify assumptions, contextualise a map pair | Deep Research | request → AIA validates; within envelope no repeat confirmation |
| Budget lift, report approval, keep/flag respondents | Human decision | commands refuse the Lead |
| Change Sociomap methodology | Typed command | refused here; Settings → Metodika (administrator), new run |
