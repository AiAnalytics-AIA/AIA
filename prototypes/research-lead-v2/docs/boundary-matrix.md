# Research Lead boundary matrix

Generated by `npm run docs` from `src/model/inventory.ts`. Inspected: AiAnalytics-AIA/AIA `develop` @ `50547cdc8d90a282af1d2e94bcd8e835df7178f9`; open-webui/open-webui `dev` @ `aa8ce52c7a3afbb164bc16a3b7c20e40ba6390ed`.

What the Lead may read, propose, operate (visual) and invoke, and the mutations it is refused. Refusals are enforced in the command, not in the prompt: `acceptProposal`, `acceptWorking`, `startRun`, `liftBudget`, `approveReport` and `choose` refuse any caller but a person (`src/app/commands.ts`).

| Area | Reads | Proposes | Operates (visual) | Invokes | Prohibited |
|---|---|---|---|---|---|
| Brief, Design, Questionnaire, Audience, Dimensions | accepted revision + working copy | element ops as a proposal | open, focus, select | bounded specialist workers | accept a proposal; accept a working copy; edit protected items; change methodology |
| Sample / readiness | readiness, outlook, forecast | — | open readiness item | readiness check (deterministic) | override a FAIL; start a run |
| Fieldwork | run, steps, cost, quality | decision card | open | — | start, cancel for you, lift budget, replace respondents |
| Results, Sociomap | frozen artifacts | interpretation (labelled) | select, inspect, view filter | INTERPRETATION_RESEARCH within envelope | change numbers, pairs, layout, thresholds; feed external evidence into computation |
| Analysis | modules, admitted claims, blocked claims | coding themes (proposed capability) | open finding / claim | analysis worker within run | admit a claim; approve its own findings; write numbers not admitted |
| Report | draft, refs, review state | tracked changes per section | focus section | section composer, claim check | approve; produce a client report for a fictional run |
| Deep Research | envelope, runs, bundles | evidence annotations | open envelope | request → AIA validates | set scope, class, route or budget by its arguments; paraphrase confidential or respondent data into public search |
| Models | — | — | — | only through GovernedModelGateway (bedrock-eu-primary) | choose a provider; call a model directly |
