# Navigátor kroků (StageNavigator)

The eleven stages in six phases (Návrh výzkumu, Vymezení vzorku, Sběr a evidence, Interpretace a předání …), square (radius 0), each stage its name and its state word with a 14 px glyph; a 3 px top edge in the state's colour; the current stage on `signal-wash` with a 2 px signal underline; a coral dot when the working copy reopened it since the newest run. Phase tints fade in, at most 9 %.

**Built** `ResearchStages` / workbench navigator (#840); v2 keeps it and moves its glyphs to StatusGlyph.
