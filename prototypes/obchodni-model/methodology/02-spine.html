The spine

A type-2 study is eight steps. The client's rule is written at the first and applied, as written, at the sixth. Everything between them exists to make that application honest. The canvas's navigator shows nine screens: the outline and the report are one step, because the report's structure is built once and printed once (the scope, § 1).

The scope's acceptance and waves

The scope (§ 6) makes the answer key the test, in six lines: A1 the three traps priced; A2 the EPC exclusions, the overrun from the comparables, spot purchases while late, tax reliefs out of the pre-tax rule, the kilogram and USD rows read right; A3 the rule applied as written at 8, 6 and 10 %, with the boundary printed where a declared judgement moves the verdict; A4 the renewal and Hanshin prices named as the assumptions most worth checking; A5 the report's structure R2-P01…P18 with every number graded and sourced and the tables from the same computation; A6 the same bytes on a rerun and a changed input refused without re-running downstream. Its waves (§ 7) build the steps in order over ten weeks: W1 Zadání a Data, W2 Předpoklady a Model, W3 Budoucnosti a Rozhodnutí, W4 Informace a mapy, W5 Zpráva a přijetí, each ending in a slice that runs on the ChemVitro files with nothing paid.

The rules the whole spine keeps

  • The client's rule decides. It is written before any result and judged as written (K3). Anything else the study computes is evidence for "what could change the conclusion", not for the recommendation (review R3, R10).
  • A number is a reference to its origin. It carries a source, a method, an uncertainty and a validation status (review I3). A number the origin does not support is not printed.
  • Unknown is never good. A missing input keeps a range; a gate that is unknown blocks the recommendation until it is evidenced (review R2). A probability is a share of the model's futures, never a claim about the world.
  • Models propose, code computes, a person approves. AIA's standing rule (ADR 0046 decision 1). A language model drafts text and suggests ranges; every number in the report comes from a program that gives the same bytes on a rerun.
  • A method the register does not hold stays provisional. Its results print odhad (metoda čeká na schválení metodikem), and a recommendation that rests on it stays předběžné doporučení (review R9, proposed; chapter 12).
  • Changes propagate. A revised input marks every downstream result and approval stale until someone reviews it (K4). Every extra computation changes one assumption at a time and says so (R2-P15).
