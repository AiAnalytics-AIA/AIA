# Karta Vedoucího (LeadCard)

One card is one action (CARD-1), in the Lead's conversation: an icon, an eyebrow (who asked: "Váš příkaz", "Návrh Vedoucího"), the title, its state pill; why in one line; the facts with the amount first ("Cena nejvýše 0,40 USD · z rozpočtu studie · zbývá 38,80 USD"); then the actions, the paid one an AI button leading with its amount. A running card streams AIA's own words with times, never a percentage. Radius 10 (UI-3).

**Replaces** `workbench/LeadCards.tsx` pills (`.statepill` r2 → status pill r6); the card form itself matches.
