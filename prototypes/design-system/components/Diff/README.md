# Změny (Diff)

A line diff with a "+n −m" summary: added lines on `diff-add`, removed on `diff-del` struck through, line numbers in `ink-faint`. The second and last green in the product ("the plus minus green red system … like code").

**Use** for system prompts, methodology versions and a report version's hand edits.

**Replaces** nothing in tokens today: `diff-*` exist only in core v3; v2 adds them to `tokens.json`.
