# Tabulka (Table)

Square (radius 0), header 12/500 `ink-muted` on `surface-sunken`, cells 8 × 10, rows 36 (compact 28), 13 px body, numbers right-aligned in tabular figures. A row that needs this person is in the coral wash; one waiting on others in the slate wash. Settings builds it as a CSS grid with table roles (`.tbl`), the stages as a table (`.stbl`); both read the same.

**Rules** the header stays in view while the body scrolls (proposal, see Návrhy); an empty table says what would be here and how it gets here; suppressed values are named, never a number.

**Replaces** the 36 hand-made tables (no shared Table today), workbench `.tbl` cells 6 × 8. A shared `Table` component is new in v2.
