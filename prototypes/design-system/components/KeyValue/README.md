# Údaje (KeyValue, Facts)

Label and value pairs: `.kv` on Settings (label column 200 px, `ink-faint`), `.facts` in Lead cards and stage sides (110 px, ruled rows; the key fact bold with its caption under it).

**Use** for what a dialog, card or section states: what is deleted and what stays, what a start costs, a version's provenance.

**Rule** an unknown value reads in words ("neznámá", "nezaznamenáno"), never 0 or a dash.
