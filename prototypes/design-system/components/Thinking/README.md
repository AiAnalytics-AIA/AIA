The real thinking-orbs 0.3.2 (MIT, `components/brand/ActivityOrb.tsx`) in `spark-1` when a model works and `status-running` when code does; shown only while the API reports a step RUNNING, `aria-hidden` beside the status word it decorates. 64 px in a running step's panel, 32 px by default, 22 in the chat. Off under reduced motion (the word stays).
