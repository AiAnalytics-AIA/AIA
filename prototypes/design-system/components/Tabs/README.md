# Záložky (Tabs)

Tabs that change what the page shows: text buttons 40 px high on a hairline, the chosen one `ink` with a 2 px `signal` underline (Settings' `.subtabs`). Keyboard: arrows between tabs, `role="tablist"`. A disabled tab says why ("jen Metodik").

**Use** for views of one thing (a methodology module's Výpočet, Verze a aktivace, Porovnání, Upravit; Výsledky' Data, Sociomapa, Analýza, Zpráva). Choosing a value is Segmented, not Tabs.
