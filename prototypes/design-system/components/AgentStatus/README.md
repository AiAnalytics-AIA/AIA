# Stav Vedoucího (AgentStatus)

While the Lead or an AI job works, one line above the composer says:
- what it does now, in its own reported words;
- how long it has run;
- a **Zastavit** button that is always there.

Its steps fold open beneath it ("Kroky (4)"). When it ends, the line becomes the turn's result, and edits wait as per-change review.

**Rules**
- Stop never asks first. It cancels and says "Zastaveno · nic se nezměnilo" or what was kept.
- The orb is shown only while the API reports RUNNING (`ActivityOrb`). A model works: spark-1 cyan, and the card's spark edge turns. Code works: petrol.
