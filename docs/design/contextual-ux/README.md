# Contextual Research and Settings design sources

Actual Claude Design R1/S1 exports from the existing AIA design project, obtained
through the authorized browser export on 13 October 2026. `manifest.json` records
the export hashes; `foundation-check.json` compares 118 core token/font/asset and
baseline screen files before and after the new variants: all unchanged.

These are design references, not application code. The component layouts load
`/styles.css` from the original design project. Implementations use AIA's existing
components and tokens rather than shipping prototype scripts or fake API state.
The full project archives and standalone variants remain local review artifacts.

The API determines editability, effective values, quotas, validation, approvals,
job timing and mathematical semantics. Prototype limits, example data, simulated
response times and browser storage are not implementation authority. In
particular, AIA retains its study-session drafts and explicit discard guards;
no client research content is added to persistent browser storage by this change.

Research uses the existing advice actions and stage mapping. Settings keeps all
eight hash IDs and separate propose/check/compare/save/activation operations.
