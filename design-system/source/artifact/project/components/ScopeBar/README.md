# ScopeBar

Persistent scope chrome: client accent band, monogram, client / study, study status, revision and role.

**The consumer provides:** `clientId`, `accent` (the persisted slot), `code`, `client`, `study`, `studyStatus`, `revision`, `role`, `deliveredAt`; or `above` + `note` for cross-client screens.

**Use:** Put it at the top of every screen. It is sticky and nothing may cover it.

**Don't:** Never omit the client name, even when the accent looks sufficient. Delivered, archived and cancelled studies get the read-only plate automatically.
