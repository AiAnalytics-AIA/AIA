# EvidenceMark

The epistemic grade mark: ■ measured, ▣ calibrated, □ modelled, ⬚ holdout pending, ? unknown.

**The consumer provides:** `role` (a domain evidence role string; anything unrecognised becomes “?”), `size` (8px default), `inSvg` when placed inside an SVG.

**Use:** Place it after a figure, in a report margin, or on a chart label.

**Don't:** Never colour it. Never map a missing role to ■. Never render it as a text character — the fonts do not contain these glyphs.
