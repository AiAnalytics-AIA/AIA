# Icon

The AIA icon set: 24 grid, 1.5 stroke, square caps.

**The consumer provides:** `name` (see the Icons asset group), `size`, `label` (makes it an image with an accessible name; otherwise decorative).

**Use:** Pair icons with text in navigation and actions.

**Don't:** Never use an icon to stand for a status — use `StatusGlyph`. No emoji.
