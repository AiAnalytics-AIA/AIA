# StatusGlyph

The 16-unit status glyph set: shape carries the state.

**The consumer provides:** `tone` (`running`, `you`, `world`, `fault`, `recovery`, `done`, `done-warn`, `ready`, `inert`, `blocked`, `invalid`, `cancelled`, `skipped`), `size`. Colour comes from `currentColor`.

**Use:** Use it inside chips, rail cells, timelines and large empty/parked panels (24–32px).

**Don't:** Never use it as decoration or as a bullet. The `you` glyph's bars are holes, so it reads on an amber fill and on a surface alike.
