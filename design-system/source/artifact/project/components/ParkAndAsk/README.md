# ParkAndAsk

The spending-authorisation dialog when work parks on budget.

**The consumer provides:** `clientId`, `accent`, `client`, `study`, `what`, `modelRole`, `provider`, `amount`, `basis`, `remaining`, `limit`, `currency`, `canApprove`.

**Use:** Open it from a parked-on-budget row or banner.

**Don't:** No default action: focus opens on the heading. Without APPROVE_BUDGET the approve action becomes “Požádat vedoucí studie”. Always state what happens on decline.
