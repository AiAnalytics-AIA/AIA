# ClientMonogram

A client's two-letter monogram on its accent.

**The consumer provides:** `clientId`, `accent` (slot 1–6 from the server; falls back to the hash), `code`, `name`; or `above`.

**Use:** Use it on rows of cross-client lists and in the scope bar.

**Don't:** Never use a client accent anywhere else: not on data, not on status, not as a button colour.
