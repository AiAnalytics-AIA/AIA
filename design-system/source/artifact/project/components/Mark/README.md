# Mark

The AIA mark: a 5 × 5 population lattice resolving into A, the apex in signal.

**The consumer provides:** `size`, `mono`.

**Use:** Use it in the scope bar, at ≥ 20px. Below 20px use the favicon-16 asset.

**Don't:** Do not recolour the apex to anything but `signal` or the mono ink. Keep one lattice pitch of clear space.
