# Logos

- `aia-mark.svg` — the population lattice resolving into A. Ink `#151a20` (`ink`, light) with the apex in `#006b9f` (`signal`, light). Use on paper at ≥ 20px.
- `aia-mark-on-graphite.svg` — on a graphite tile: points `#ece9e4`, apex `#6ac5e8` (`ink` and `signal`, dark).
- `aia-mark-mono-black.svg` / `aia-mark-mono-white.svg` — one ink, for one-colour print and embossing.
- `aia-wordmark.svg`, `aia-wordmark-on-graphite.svg`, `aia-wordmark-mono.svg` — the I is a column of five individuals. Minimum height 16px.
- `aia-lockup.svg`, `aia-lockup-mono.svg` — wordmark + "Agentic AI Analytics" in IBM Plex Sans Medium, outlined to paths. Minimum height 24px.

Clear space: one lattice pitch (⅙ of the mark's width) on every side. Never recolour the apex to anything but `signal` or the mono ink; never place on a gradient or photograph.
