# Favicons and app icon

`favicon-16.png` / `favicon-16.svg` — the six-point pyramid (no faint field) for 16px; `favicon-32.png`, `apple-touch-icon-180.png`, `icon-512.png` and `app-icon.svg` — the full lattice on graphite `#0f1215`, points `#ece9e4`, apex `#6ac5e8`. They replace `apps/web/src/app/favicon.ico` and the Next.js defaults in `apps/web/public/`.
