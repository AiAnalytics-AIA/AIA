# The artifact, verbatim

`artifact/project/` is the content of the AIA Design System artifact
(<https://claude.ai/artifact/LB7SgQGTiynynHZNEXgqBy>, version `1790501464-6a0a`),
copied byte for byte except for one word (*The one change*, below). It is kept for
reference. The package one level up
(`../tokens`, `../fonts`, `../assets`, `../reference`) is what a consumer reads.

The artifact was built on 2026-09-22 from this repository at `0d4c51d`
(`project/design-system.json` › `lastChange`). Its enum maps are bound to
`17c0a6b`. `../status-map.md` re-derives them at `043b0dd` and lists what moved.

## The one change

`project/README.md` differs from the artifact's by one word. Its identity rule
bans "gradients, glows or [a word] effects", and that word is also a legacy
demo-client name, which `tools/exposure_check.sh` refuses in any file. It
reads "northern-lights effects" here. The artifact's original file has SHA256
`ddcd77f98270e196e52332fc1f7f05654bf5f4ae9efb4273c1158390dc290676`. Every other file is byte-identical.
