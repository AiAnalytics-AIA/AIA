Colour · semantic UI (structure, text, selection, focus)

--surface1,00:1 on surfacePage ground in Studio. Light: paper with a faint warm cast so eight-hour sessions do not glare. Dark: graphite. Every text token is verified against it.
--surface-raised1,05:1 on surfacePanels, table bodies, cards, the stage rail track. One step above `surface`; separated by `border`, never by shadow.
--surface-sunken1,07:1 on surfaceWells: table headers, inputs, code and fingerprint blocks, the budget meter track.
--surface-overlay1,06:1 on surfaceDialogs and popovers only (the park-and-ask dialog, command palette). Pairs with `shadow-overlay`.
--border1,33:1 on surfaceHairline dividers between rows, panels and cells. Decorative; never the only boundary of a control.
--border-strong3,66:1 on surfaceControl borders (inputs, secondary buttons, checkboxes) and the scope bar edge. >= 3:1 on every surface in both themes.
--ink16,24:1 on surfacePrimary text and every figure a conclusion rests on. >= 7:1 (AA-plus) on all surfaces and status washes in both themes.
--ink-muted8,55:1 on surfaceSecondary text: labels, metadata, table headers. >= 4.5:1 on surface, raised, sunken and overlay.
--ink-faint5,80:1 on surfaceTertiary text: timestamps, hints, NOT_STARTED stages. >= 4.5:1 on all four surfaces — faint, never illegible.
--surface-inverse16,24:1 on surfaceInverse fields: the RECOVERY_REQUIRED block, tooltips, the keyboard-shortcut overlay.
--ink-inverse1,00:1 on surfaceText on `surface-inverse`.
--signal5,41:1 on surfaceThe one precise accent: selection, links, the live edge of a RUNNING process, the primary action. Used sparingly — never decoration, never for a warning.
--signal-wash1,12:1 on surfaceSelected row / selected stage background. `ink` stays >= 7:1 on it.
--on-signal1,05:1 on surfaceText and icons on a solid `signal` fill (primary button).
--focus-ring5,41:1 on surfaceThe 2px focus outline, always drawn with a 2px `surface` gap so it sits on a known ground; >= 3:1 on every surface in both themes.
--selection = signal-wash1,12:1 on surfaceAlias of `signal-wash` for selected rows, nodes and text ranges.

Colour · status (the state of a stage, run, step or reservation; nothing else)

--status-running5,41:1 on surfaceRUNNING / EXECUTING: the machine is working, nothing is needed from you. Same hue as `signal` on purpose: the live edge.
--status-running-wash1,12:1 on surfaceBackground of a running row or stage cell.
--status-you1,77:1 on surfaceRESERVED for "parked, waiting on a person" (WAITING_USER, AWAITING_GATE, AWAITING_BUDGET, WAITING_CREDITS). Solid fill, the loudest thing on any screen. Never used for anything else — not warnings, not highlights, not a data series.
--on-status-you16,24:1 on surfaceLabel and glyph on a solid `status-you` fill. >= 7:1.
--status-you-ink5,29:1 on surfaceWaiting-on-you text and glyphs on ordinary surfaces (the count in the nav, an inline "čeká na vás").
--status-you-wash1,06:1 on surfaceRow background for a parked-on-you item in Portfolio and run logs.
--status-world5,54:1 on surface"Parked, waiting on the world": WAITING_PROVIDER, WAITING_CAPACITY. Slate — calm, not alarming, visibly not running.
--status-world-wash1,14:1 on surfaceRow background for a waiting-on-the-world item.
--status-fault5,99:1 on surfaceFAILED and SCHEMA/PERMISSION failure text and glyphs; the uncertain part of the budget meter. Always with the × glyph and a label.
--on-status-fault1,05:1 on surfaceText on a solid `status-fault` fill.
--status-fault-wash1,09:1 on surfaceRow background for a failed item.
--status-recovery16,24:1 on surfaceRECOVERY_REQUIRED block fill: inverse ink. The rarest, most serious state — a decision about money that may already be spent.
--on-status-recovery1,00:1 on surfaceText on the recovery block.
--status-recovery-hatch3,70:1 on surfaceThe 45-degree hatch band along the recovery block edge. >= 3:1 against `status-recovery`.
--status-done16,24:1 on surfaceDONE / COMPLETED / SUCCEEDED glyph: plain ink. Done is quiet, not celebratory — there is no green in the status family.
--status-inert5,80:1 on surfaceNOT_STARTED, BLOCKED, CANCELLED, SKIPPED, INVALIDATED glyphs and labels.

Colour · achromatic evidence, null and budget marks (carried by form, survive greyscale)

--evidence-mark = ink16,24:1 on surfaceEvidence-grade marks (the grade glyph, dashed/dotted underlines, hollow nodes). Achromatic by design so the grade survives greyscale print and never collides with status or data colour.
--evidence-hatch = ink-faint5,80:1 on surfaceHatch strokes for modelled bars and cells.
--null-mark = ink16,24:1 on surfaceThe "not available" glyph and label. Full ink: missing data is information, never softer than a bad value.
--suppressed-fill = ink-muted8,55:1 on surfaceThe solid redaction bar of a suppressed value.
--budget-spent = ink16,24:1 on surfaceSettled spend segment of the budget meter.
--budget-reserved = signal5,41:1 on surfaceReserved-but-unsettled segment, drawn hatched.
--budget-uncertain = status-fault5,99:1 on surfaceSETTLED_UNCERTAIN segment: money that may already be gone. Hatched and labelled, never rounded into spent.

--doc-paper1,00:1 on doc-paperDeliverable register page. Identical in both themes: the report is paper even when the Studio is dark.
--doc-ink18,49:1 on doc-paperReport prose and figures. 17:1 on `doc-paper`.
--doc-muted9,06:1 on doc-paperReport captions, running heads, footnotes.
--doc-rule1,72:1 on doc-paperReport table rules and figure frames.
--doc-accent8,27:1 on doc-paperReport section numbers and the cover rule. The only colour a printed report needs; prints as dark grey.

Colour · semantic UI (structure, text, selection, focus)

--surface1,00:1 on surfacePage ground in Studio. Light: paper with a faint warm cast so eight-hour sessions do not glare. Dark: graphite. Every text token is verified against it.
--surface-raised1,08:1 on surfacePanels, table bodies, cards, the stage rail track. One step above `surface`; separated by `border`, never by shadow.
--surface-sunken1,05:1 on surfaceWells: table headers, inputs, code and fingerprint blocks, the budget meter track.
--surface-overlay1,16:1 on surfaceDialogs and popovers only (the park-and-ask dialog, command palette). Pairs with `shadow-overlay`.
--border1,48:1 on surfaceHairline dividers between rows, panels and cells. Decorative; never the only boundary of a control.
--border-strong4,05:1 on surfaceControl borders (inputs, secondary buttons, checkboxes) and the scope bar edge. >= 3:1 on every surface in both themes.
--ink15,52:1 on surfacePrimary text and every figure a conclusion rests on. >= 7:1 (AA-plus) on all surfaces and status washes in both themes.
--ink-muted9,71:1 on surfaceSecondary text: labels, metadata, table headers. >= 4.5:1 on surface, raised, sunken and overlay.
--ink-faint6,78:1 on surfaceTertiary text: timestamps, hints, NOT_STARTED stages. >= 4.5:1 on all four surfaces — faint, never illegible.
--surface-inverse15,52:1 on surfaceInverse fields: the RECOVERY_REQUIRED block, tooltips, the keyboard-shortcut overlay.
--ink-inverse1,00:1 on surfaceText on `surface-inverse`.
--signal9,63:1 on surfaceThe one precise accent: selection, links, the live edge of a RUNNING process, the primary action. Used sparingly — never decoration, never for a warning.
--signal-wash1,39:1 on surfaceSelected row / selected stage background. `ink` stays >= 7:1 on it.
--on-signal1,05:1 on surfaceText and icons on a solid `signal` fill (primary button).
--focus-ring9,63:1 on surfaceThe 2px focus outline, always drawn with a 2px `surface` gap so it sits on a known ground; >= 3:1 on every surface in both themes.
--selection = signal-wash1,39:1 on surfaceAlias of `signal-wash` for selected rows, nodes and text ranges.
